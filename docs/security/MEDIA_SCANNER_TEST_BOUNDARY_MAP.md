# Media-scanner test-boundary map

[Documentation map](../README.md) · [Testing](../TESTING.md)

This map records where the preserved pre-variance M2B security boundaries are enforced after the M2R
pull-worker redesign. The scanning control plane is metadata-only; this document does not extend that
claim to unrelated Edge provider transports.

| Preserved boundary                                                                                                         | Current authoritative coverage                                                                                                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Push gateway bearer auth, bounded body, duplicate headers, and server ingress                                              | Push media ingress is retired. `scan-upload/index.test.ts` statically prohibits media-body operations; `scanner-control/index.test.ts` and `_shared/scanner-control.test.ts` cover HMAC, exact action/attempt, bounded control JSON, replay, runtime route, and safe errors. |
| Strict request/result contracts and canonical signing                                                                      | `_shared/scanner-control.test.ts`, the shared golden JSON, scanner `contracts.test.ts`, `manifest.test.ts`, and `control-client.test.ts`.                                                                                                                                    |
| Full-media Edge memory bounds                                                                                              | `pnpm test:edge-memory` imports the production scanner-control handler, exercises 10/20-MiB metadata and malformed maxima, enforces the explicit scanning inventory, and fails above 128 MiB or on size-proportional growth/body/Base64/hash/upload operations.              |
| Storage capability origin and redirect denial                                                                              | Scanner `capability-http.test.ts`, `worker.test.ts`, and Edge `s3-capability.test.ts` cover exact origins/paths/query keys, suffix/encoding/traversal/scheme/port/userinfo/IP/IPv6/private-host denial, redirects, stale attempts, and deadline clipping.                    |
| Pipeline ordering, two scans, cancellation, deadline, queue overload, and response loss                                    | Scanner `v2-pipeline.test.ts`, `worker.test.ts`, `deadline.test.ts`, the real container gate, and `test-media-scanner-supabase.mjs`.                                                                                                                                         |
| ClamD framing, malformed replies, timeout, abort, refused socket, reload, and redaction                                    | Scanner `clamd-stream.test.ts` and `clamd-freshness.test.ts`, plus real EICAR/fresh/stale/missing/unparseable/future/reload container probes.                                                                                                                                |
| Image malformed structure, dimensions/pixel/decompression bombs, animation/multipage/ICC/XMP, native reopen, and polyglots | Scanner `v2-media-policy.test.ts`, `max-image.test.ts`, `isolated-sanitizer.test.ts`, and max-policy real container probes.                                                                                                                                                  |
| Legacy MP4/WebM structural pass-through                                                                                    | Removed. `ffmpeg-remux.test.ts` plus `pnpm test:media-scanner:remux` prove real approved M4A/audio-MP4/video-MP4 remux; WebM and PDF fail closed.                                                                                                                            |
| Sanitizer timeout, process-tree kill, native-memory reuse, and temporary residue                                           | Scanner `isolated-sanitizer.test.ts`, `ffmpeg-remux.test.ts`, and real three-job child-isolation/remux probes.                                                                                                                                                               |
| Promotion, completion replay, old-attempt isolation, and no duplicate jobs                                                 | Edge scanner-control/scan-upload tests, pgTAP upload-security tests, real database concurrency harness, and real Supabase integration.                                                                                                                                       |
| Cleanup aging, leases, dead letters, item isolation, and active/final preservation                                         | pgTAP cleanup tests, privacy-worker tests, and the real 25-hour Storage-object integration.                                                                                                                                                                                  |
| Attestation and request replay                                                                                             | Private one-shot nonce pgTAP/concurrency tests and scanner-control handler tests.                                                                                                                                                                                            |
| Protected-media authorization                                                                                              | `media-access/index.test.ts` preserves M1 live owner/party/block authorization and streaming response behavior.                                                                                                                                                              |

`ai-diagnostic` and `transcribe` still require clean-authorized, purpose/owner/size-bound media. Their
provider media-transfer and memory architecture is an explicit M3 gate before live AI or voice
activation; it is not claimed as M2 scanning-control evidence.

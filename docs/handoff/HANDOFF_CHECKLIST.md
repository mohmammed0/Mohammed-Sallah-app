# Handoff checklist

- [x] Canonical isolated branch created from the complete PR chain.
- [x] Starting baseline and ancestry recorded.
- [x] Duplicate logical completion-rejection notification fixed test-first.
- [x] Mobile CI visual-module test boundary fixed.
- [x] Generated database types updated.
- [x] Tool ownership, UI allowlist/denylist, state catalog, and contract process documented.
- [x] Machine-readable manifest and automated checks added.
- [x] Final current-state documentation reconciled.
- [x] Frozen install and complete applicable exact-head local gates PASS; the
      documented Windows Supabase CLI bootstrap limitation is delegated to hosted Linux.
- [x] Final Codex Security diff and full-repository reviews have zero unresolved
      P0/P1 and no deferred security-critical coverage.
- [ ] Exact-head hosted required jobs PASS.
- [ ] Final Draft PR created, linked, and left Draft with auto-merge disabled.
- [ ] Old PRs/issues receive accurate supersession/status comments after green CI.
- [ ] Worktree/index clean and local equals upstream.

Production, store submission, paid services, merge, and physical-device claims
are not checklist items for engineering handoff.

# Notion and Linear handoff

Use the machine-readable manifest, final Draft PR, validation evidence, external
gates, and multi-tool backlog as synchronization inputs.

Create epics by customer, provider, admin, design system, external gates, and
final release audit. Each issue needs owner, source SHA/PR, affected route,
acceptance criteria, allowed paths, tests, dependency, and status label:
`PASS`, `FAIL`, `NOT RUN`, or `HUMAN INPUT REQUIRED`.

Never store passwords, API keys, tokens, private paths, media, documents, exact
locations, or sensitive logs. Git remains authoritative for code/contracts;
Notion/Linear track delivery and must not silently redefine scope.

# Screen inventory

## Mobile shared/auth

Welcome/landing, sign-in and recovery, auth callback, startup recovery,
notifications, support, saved locations, account/privacy, and role switching.

## Customer

Home, service categories, AI request composer, text/image/audio intake,
transcript/clarification, location, timing, review/publish, request list/detail,
offer comparison, selected job timeline, messaging, completion decision, rating,
and support/dispute states.

## Provider

Dashboard, onboarding steps, verification state, service/area/availability,
eligible request feed, translated brief, offer editor, jobs, active-job timeline,
messages, completion evidence, earnings/status, notifications, account, support.

## Web

Public locale pages, login, account-deletion entry, and admin dashboard sections
for customers, providers, requests, jobs, catalog, moderation, support, finance,
audit, and enforcement.

Every screen requires loading, empty, safe error, offline/retry, forbidden, and
large-text behavior where applicable. See [UI state matrix](UI_STATE_MATRIX.md).

# Multi-tool backlog

## Figma

1. Confirm brand direction and token values without changing functional status semantics.
2. Design complete customer/provider/admin screen sets and all matrix states.
3. Prototype request → offer → job → completion and provider onboarding → offer flows.

## Claude Code

1. Start from the exact canonical SHA and read the prescribed files.
2. Implement one reviewed Figma slice at a time inside the UI allowlist.
3. Add visual/rendering tests and run affected package plus UI-boundary checks.

## Canva

Create approved launch/presentation assets only after the brand and claims are
approved. No product code or private screenshots.

## Notion/Linear

Mirror the final PR, external gates, UI slices, owners, and acceptance criteria.
Do not mark Production, store, physical-device, or legal gates complete from
engineering handoff evidence.

Any functional request is routed back to Codex through the contract-change process.

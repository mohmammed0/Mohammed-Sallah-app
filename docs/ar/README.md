## السياسة اللغوية

- العربية لغة التصميم والملاحة الأولى.
- الإنجليزية تبقى للمعرفات التقنية وأسماء الأوامر وواجهات البرمجة ومسارات الملفات.
- النصوص المرئية في المنتج تمر عبر مفاتيح مشتركة للعربية والإنجليزية والأردية والهندية.
- المستندات التقنية الإنجليزية تحت architecture وsecurity وoperations وprivacy وrelease وstore
  هي مراجع حالية؛ لا تعني ترجمة الملخص العربي إنشاء عقد تقني بديل.

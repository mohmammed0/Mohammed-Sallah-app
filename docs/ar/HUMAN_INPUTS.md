[إجراء النشر](../operations/LEGAL_PUBLICATION.md) الحقول والترتيب المطلوبين.

## الهوية والقانون

- الاسم التجاري العام والتهجئة العربية والإنجليزية.
- الكيان القانوني السعودي وسياسة الخصوصية والشروط والاحتفاظ وصياغة الموافقات.
- بريد الدعم العام وURL الدعم والخصوصية والشروط.
- مراجع قانونيون وخصوصية وتعريب محترفون.

## الحسابات والاعتمادات

- مشروع Supabase الإنتاجي وأسراره.
- حساب Apple والتوقيع وiOS/TestFlight، وسلطة الإرسال إلى حسابات المتاجر.
- اعتماد Maps والإصدارات والتوقيع والحصة للـProduction؛ مفتاح Preview المقيد ليس اعتماد إنتاج.
- مشروع OpenAI للـProduction وموافقات النص والصورة والصوت والترجمة وDPA والمنطقة والاحتفاظ.
- دليل Push فعلي على الجهاز، وAPNs للـiOS، وملكية تدوير أسرار Production وجدول العامل.
- SMS والدفع والمراقبة والتنبيهات وموارد ماسح Production وشبكته وTLS ومراجعة GPL.

## التشغيل والأدلة

- حسابات مراجعة حقيقية معتمدة.
- ملاك تشغيل ومراجعة بأقل صلاحية للخصوصية والمالية والدعم والتحقق.
- سياسة تحقق مقدم الخدمة والأدلة المطلوبة.
- RPO/RTO وملكية الاستعادة والاستجابة للحوادث.
- أدلة Android الفعلية: الموقع والخرائط والكاميرا والمعرض والصوت ولوحة المفاتيح وإتاحة الوصول.

## قاعدة الإبلاغ

هذه البنود **HUMAN INPUT REQUIRED** حتى يوفرها مالك مخول ويثبتها. لا تصبح PASS بسبب اكتمال
الكود. أدلة Preview الحالية لا تمنح تصريح Production أو المتاجر أو الفوترة أو الجهاز الفعلي.

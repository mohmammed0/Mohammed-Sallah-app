# المدخلات البشرية المطلوبة

[القائمة المرجعية الكاملة](../HUMAN_INPUTS.md) · [التوثيق العربي](README.md)

لا يجوز للكود أو للمساهم اختلاق القيم التالية أو تمثيل placeholder بوصفه جاهزية إنتاجية. راجع
[القائمة الإنجليزية الكاملة](../HUMAN_INPUTS.md) للأصحاب والموعد والبديل الآمن لكل بند.

## الهوية والقانون

- الاسم التجاري العام والتهجئة العربية والإنجليزية.
- الكيان القانوني السعودي وسياسة الخصوصية والشروط والاحتفاظ وصياغة الموافقات.
- بريد الدعم العام وURL الدعم والخصوصية والشروط.
- مراجع قانونيون وخصوصية وتعريب محترفون.

## الحسابات والاعتمادات

- مشروع Supabase الإنتاجي وأسراره.
- حسابات Apple/Google وEAS ومعرفات التطبيق والتوقيع.
- مفتاح Android Maps مقيد بالحزمة وSHA-1 الصحيح.
- بيانات OpenAI أو مزود AI المعتمد وشروط المعالجة.
- مزود الترجمة وDPA والمنطقة والاحتفاظ.
- SMS وAPNs/FCM/Expo Push والدفع والمراقبة وفحص البرمجيات الخبيثة.

## التشغيل والأدلة

- حسابات مراجعة حقيقية معتمدة.
- ملاك تشغيل ومراجعة بأقل صلاحية للخصوصية والمالية والدعم والتحقق.
- سياسة تحقق مقدم الخدمة والأدلة المطلوبة.
- RPO/RTO وملكية الاستعادة والاستجابة للحوادث.
- أدلة Android الفعلية: الموقع والخرائط والكاميرا والمعرض والصوت ولوحة المفاتيح وإتاحة الوصول.

## قاعدة الإبلاغ

هذه البنود **HUMAN INPUT REQUIRED** حتى يوفرها مالك مخول ويثبتها. لا تصبح PASS بسبب اكتمال
الكود. لا تبدأ R1 بناء EAS أو تنشئ سراً أو تفعل فوترة أو تنشر خدمة.

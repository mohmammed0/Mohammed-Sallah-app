# حسابات اختبار النسخة التجريبية | Closed Beta Test Accounts

**البيئة:** Supabase Preview غير الإنتاجية فقط
**تنبيه:** هذا الملف يسجل عناوين البريد والأدوار فقط. كلمات المرور وبيانات الاسترداد وأي رموز دخول
تبقى خارج Git وفي مخزن المالك المعتمد.

This repository file contains account identifiers and expected roles only. It must never contain
passwords, JWTs, recovery links, service-role credentials, private documents, or signed URLs.

## سياسة الاستخدام | Usage policy

1. استخدم بيانات اصطناعية واضحة فقط، ولا تدخل اسم شخص حقيقي أو هوية أو عنوانًا دقيقًا أو مستندًا
   حقيقيًا أو وسائط خاصة.
2. لا تنشئ نسخة مكررة من هذه الحسابات ما دام الحساب المعتمد يعمل.
3. استخدم مسارات الواجهة/RPC/Edge العادية؛ لا تعدل الجداول مباشرة لتجاوز onboarding أو التحقق أو
   قبول الطلبات أو حالات المهمة.
4. يجب أن تمر وسائط الاختبار الخاصة عبر upload ticket وquarantine والماسح والترقية النظيفة.
5. لا تعرض الموقع الدقيق لمقدم الخدمة قبل الحالة المصرح بها، ولا تكشف عروض المنافسين.
6. سجّل نتيجة المسار كـ `PASS` أو `FAIL` أو `NOT RUN` مع SHA ووقت UTC من دون محتوى خاص.
7. ألغِ أو أكمل الطلب الاصطناعي عبر المسار المدعوم، ثم أزل uploads/jobs/objects المؤقتة.
8. عند الاشتباه في اعتماد الحساب، أوقف الاختبار واطلب تدويرًا من المالك؛ لا تنسخ السر إلى Git أو
   دردشة أو سجل.

## المسار الدخاني المتوقع | Expected smoke journey

- **Customer:** تسجيل الدخول → اختيار التكييف → وصف AI اصطناعي → موقع محاكى في الرياض → مراجعة →
  نشر → مقارنة عرض → اختيار → مراسلة → إكمال → تقييم.
- **Provider:** تسجيل الدخول → التبديل إلى مقدم الخدمة → feed → الموجز الأصلي/المترجم → العرض →
  المهمة المختارة → حالات المهمة المسموحة → دليل إكمال اصطناعي.
- **Admin:** تسجيل الدخول → رؤية العميل/مقدم الخدمة/الطلب ضمن الصلاحية → مسارات الدعم والمراجعة →
  صحة تشغيلية منقحة.

English summary: use the three fixed Preview identities with synthetic data through normal product
contracts. Credentials remain in the owner-controlled external file; no password or token belongs in
this document or repository.

# Google Play Data Safety draft

Potentially collected: account/contact data; user IDs; foreground precise/approximate location; photos/audio/text and messages; provider verification documents for provider users; physical-service financial metadata; app/device/security events. Purposes include app functionality, account management, provider verification, fraud/security, support, optional AI drafting/transcription, notifications, and legal compliance. No raw card credentials are designed to be collected. Online payment is disabled in this release; do not include a hypothetical future gateway as an active processor.

Potential recipients/processors include Supabase hosting/auth/storage, OpenAI for diagnostic/transcription content after explicit permission, maps/geocoding and configured notification/email/monitoring providers. Exact production sharing, region, encryption claims, retention, optionality, and deletion answers must match deployed configuration and contracts. Verify production TLS and at-rest settings; local development URLs do not establish production encryption evidence. Users can request export/deletion; any retained/anonymized financial or audit records must follow the approved policy. Complete [DATA_DISCLOSURE_WORKSHEET.md](DATA_DISCLOSURE_WORKSHEET.md) before final console answers.

# Screenshot plan

Capture on real target dimensions after final branding/copy and seeded review accounts. Do not show real personal data, exact addresses, phone numbers, documents, or payment references.

1. Arabic welcome/home with customer/provider switch.
2. Arabic multimodal request composer, explicit OpenAI transfer permission and separate draft approval; capture the manual alternative too.
3. Safety guidance state using synthetic non-emergency text.
4. Sealed offer comparison with synthetic values.
5. Job lifecycle/change-order approval and private chat.
6. Provider onboarding with redacted synthetic document placeholder.
7. Provider eligible-request feed showing approximate information only.
8. Account privacy/export/deletion and the readable legal-policy viewer.
9. English LTR equivalents for key customer screen.
10. Public website and secured admin dashboard for PR evidence (not store mobile slots).

Required device sets and captions follow current App Store/Play Console requirements at submission time. Automated web screenshots may be produced by Playwright; mobile store screenshots require a simulator/physical-device run and are `NOT RUN` in environments without one.

For each asset record filename, SHA-256, platform, locale, device, pixel dimensions, source SHA, binary build and capture timestamp. Keep clean original captures; overlays may describe actual visible behavior but must not simulate features or expose personal data. Existing SVG fixtures/browser captures are not native store evidence.

The app supports iPad: prepare both iPhone and iPad captures from the corresponding simulator/device. Current accepted examples include 6.9-inch portrait 1320×2868 and 13-inch iPad portrait 2064×2752; verify the exact supported slot at submission. [Apple screenshot specification](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications).

For Play prepare the 512×512 store icon, 1024×500 feature graphic and actual Android screenshots; do not stretch a phone capture into tablet evidence. Final brand/artwork approval is still needed. [Google preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en).
